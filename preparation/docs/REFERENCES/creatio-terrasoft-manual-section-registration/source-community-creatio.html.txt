            <div property="schema:text" class="clearfix text-formatted field field--name-comment-body field--type-text-long field--label-hidden field__item"><p>Здравствуйте, Дмитрий!</p>
<p>В целом, если раздел не был корректно зарегистрирован мастером в БД, лучшее решение - создать заново, ибо мастер гарантированно внесет все необходимые привязки. </p>
<p>Если всеже хотите пойти сложным путем, вот необходимый минимум таблиц, в которых раздел нужно зарегистрировать(тестировали на 7.9.2):</p>
<p>I Этап. Создать запись в таблице SysModuleEntity (таблица, где хранится информация объектах разделов):</p>
<p>SysModuleEntity</p>
<div class="geshifilter">
<pre class="cpp geshifilter-cpp" style="font-family:monospace;">insert into SysModuleEntity <span style="color: #008000;">(</span>SysEntitySchemaUId<span style="color: #008000;">)</span> values <span style="color: #008000;">(</span><span style="color: #FF0000;">'AF6DD4AD-1398-4FCE-8837-78DC65AE0F9E'</span><span style="color: #008000;">)</span></pre></div>
<p>где  [SysEntitySchemaUId] - колонка Uid объекта раздела (например, "UsrRK") в таблице SysSchema;</p>
<p>II Этап. Создать запись в таблице SysModuleEdit (страница редактирования "Page"):</p>
<p>SysModuleEdit</p>
<div class="geshifilter">
<pre class="cpp geshifilter-cpp" style="font-family:monospace;">insert into SysModuleEdit <span style="color: #008000;">(</span>SysModuleEntityId
,UseModuleDetails
,CardSchemaUId
,ActionKindCaption
,ActionKindName
,PageCaption<span style="color: #008000;">)</span>
values <span style="color: #008000;">(</span><span style="color: #FF0000;">'8ED522AF-00E1-4595-AC13-643944B005B7'</span>
,<span style="color: #0000dd;">1</span>
,<span style="color: #FF0000;">'8B22D9BE-4BBC-4B50-80EA-AB6FBB604B7E'</span>
,<span style="color: #FF0000;">'Добавить'</span>
,<span style="color: #FF0000;">'UsrRK1Page'</span>
,<span style="color: #FF0000;">'Card schema: "RK"'</span><span style="color: #008000;">)</span></pre></div>
<p>где  [SysModuleEntityId] - колонка Id записи таблицы SysModuleEntity из первого этапа (проверка Select Id from SysModuleEntity Where SysEntitySchemaUId='AF6DD4AD-1398-4FCE-8837-78DC65AE0F9E')<br>
[CardSchemaUId]  - колонка Uid страницы редактирования объекта (например, "UsrRK1Page") в таблице SysSchema (проверка Select Uid,Name from SysSchema where name like '%UsrRK%'). Нам необходима схема, которая называется "Название объекта + 1Page"<br>
[ActionKindCaption] - Название кнопки в реестре раздела;<br>
[ActionKindName] - Название схемы страницы редактирования;<br>
[PageCaption] - Заголовок схемы страницы редактирования в таблице SysSchema (проверка Select Uid,Name,Caption from SysSchema where name like '%UsrRK1Page%')</p>
<p>III Этап. Создать запись в таблице SysModule (страница раздела "Section"):</p>
<p>SysModule</p>
<div class="geshifilter">
<pre class="cpp geshifilter-cpp" style="font-family:monospace;">insert into SysModule <span style="color: #008000;">(</span>Caption
,SysModuleEntityId
,FolderModeId
,GlobalSearchAvailable
,Code
,SectionModuleSchemaUId
,SectionSchemaUId
,Image32Id<span style="color: #008000;">)</span> values <span style="color: #008000;">(</span><span style="color: #FF0000;">'RK'</span>
,<span style="color: #FF0000;">'8ED522AF-00E1-4595-AC13-643944B005B7'</span>
,<span style="color: #FF0000;">'B659D704-3955-E011-981F-00155D043204'</span>
,<span style="color: #0000dd;">1</span>
,<span style="color: #FF0000;">'UsrRK'</span>
,<span style="color: #FF0000;">'DF58589E-26A6-44D1-B8D4-EDF1734D02B4'</span>
,<span style="color: #FF0000;">'B3D153C0-92EF-4A53-B868-9395C3E43516'</span>
,<span style="color: #FF0000;">'026742D9-390C-4778-BC46-9FA85C42677A'</span><span style="color: #008000;">)</span></pre></div>
<p>где  [Caption] - Название раздела (можно брать caption объекта раздела -<br>
[SysModuleEntityId]  - колонка Id записи таблицы SysModuleEntity из первого этапа (проверка Select Id from SysModuleEntity Where SysEntitySchemaUId='AF6DD4AD-1398-4FCE-8837-78DC65AE0F9E')<br>
[Code] - Название объекта раздела;<br>
[SectionModuleSchemaUId] - UId модуля SectionModuleV2 с помощью которой открывается схему раздела;<br>
[SectionSchemaUId] - колонка Uid страницы раздела объекта (например, "UsrRK1Section") в таблице SysSchema (проверка Select Uid,Name,Caption from SysSchema where name like '%UsrRK%'). Нам необходима схема, которая называется "Название объекта + 1Section"</p>

            <div property="schema:text" class="clearfix text-formatted field field--name-comment-body field--type-text-long field--label-hidden field__item"><p>Павел, добрый день!</p>
<p>Регистрировал раздел по вашему алгоритму, т.к. мастер у меня упорно не хочет работать. Вроде бы все заработало, но столкнулся с такой проблемой: если создать делать, которая будет ссылаться на нашу новую сущность, то при формировании ссылки на карточку этого раздела ссылка будет некорректной. "Вскрытие" показало, что причина в отсутствии записи в таблице SysModule в колонке&nbsp;CardModuleUId. Без этой записи ссылка формируется без CardModuleV2 и карточка не открывается.</p>
