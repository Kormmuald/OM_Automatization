# Дочерняя спецификация 01: адаптер только для чтения и допуск полного каталога

Статус: **кандидат; запуск в рабочей среде не разрешён**.

## Цель

Построить обобщённый считыватель BPMSoft только для чтения, который воспроизводимо инвентаризирует доступный каталог, сохраняет неизвестные структуры без потери данных и проходит один контрольный этап допуска полного каталога.

## Входные данные и границы

- Кандидаты API: устаревшие `GetPackages`, `GetWorkspaceItems`, `GetSchema`, `SelectQuery`.
- Ограниченные доказательства подтверждают явный порядок/постраничную обработку по `Id` только для `ActivityPriority` и `Lookup`; это начальные данные фикстуры, а не доказательство для всего каталога.
- Считыватель не использует конечные точки записи/Manage и не создаёт `.xlsx` на этапе допуска.

## Требования

- **READ-001** Сессия хранит password/cookies/CSRF только в памяти; URL и приглашение входа интерактивны.
- **READ-002** Список разрешённых конечных точек чтения запрещает всё по умолчанию; журнал запросов сохраняет вид конечной точки и безопасные метаданные, но не тело с исходными значениями справочников.
- **READ-003** Общий постраничный считыватель требует явного стабильного порядка, проверяет дубликаты, признаки пропусков/перекрытий, монотонное завершение, ограничение числа страниц и условие окончания.
- **READ-004** Два прохода одной области на неизменной целевой системе дают одинаковые упорядоченные наборы идентичностей/количества/канонические хеши; контроль направления выполняется там, где он поддержан контрактом.
- **READ-005** Идентичность на уровне пакета сохраняется; одинаковые имена схем не объединяются.
- **READ-006** `WorkspaceInventory` содержит каждый доступный элемент со статусом `Structured|InventoryOnly|Unreadable|Unsupported` и причиной.
- **READ-007** Детальный разбор выполняется только для поддержанных контрактом областей EntitySchema/lookup; остальные виды остаются только в перечне.
- **READ-008** Неизвестный тип/свойство/структура фиксируется без потерь в обезличенной структурной диагностике. Нельзя подставлять значение по умолчанию или пропускать элемент.
- **READ-009** Элементы индекса читаются только из `schema.indexes[].columns[].columnUId`; `.uId` элемента и `ActualIndexed` не заменяют связь.
- **READ-010** Допуск дважды проходит весь доступный для чтения каталог и фиксирует количества, упорядоченные ID, хеши, пропуски/дубликаты/повторные попытки, перечень неподдерживаемых элементов, затраченное время, размеры ответов и прогнозируемые ограничения Excel.
- **READ-011** Для новой неизвестной структуры принимается одно из решений: представить без потерь, пометить как неподдерживаемую либо завести ограниченную исследовательскую задачу с точным вопросом. Блокируется только зависящая возможность.
- **READ-012** Алгоритм отпечатка целевой системы основывается только на доказанных данных чтения и метаданных версии; его допущения о коллизиях/устаревании документированы.

## Ошибочные состояния

- Отсутствие явного порядка, невоспроизводимая последовательность, дубликат/пропуск, раннее/позднее завершение: `CATALOG_ORDER_OR_PAGING_UNQUALIFIED`.
- Неоднозначная идентичность пакета/схемы: `SCHEMA_LAYER_IDENTITY_AMBIGUOUS`.
- Неизвестная структура без сохранения без потерь: критическая ошибка всего запуска допуска.
- Неподдерживаемая структура с корректным сохранением: ограниченный по области блокер, а не скрытый успех.
- Размер за пределами принятого проекта Excel: `WORKBOOK_SCALE_DECISION_REQUIRED` до реализации Excel-книг.

## Приёмка и валидация

- Автономные эталонные фикстуры: ограниченные доказательства + очищенные структуры, полученные из устаревшей системы.
- Контрактные тесты проверяют точный список разрешённых операций чтения и отсутствие вызовов конечных точек записи.
- Метаморфные тесты меняют порядок перечисления входных данных, сохраняя неизменным канонический результат.
- Негативные фикстуры с дубликатами, перекрытиями, повторной страницей, пустой промежуточной страницей, непустой последней страницей и превышением числа страниц безопасно завершаются ошибкой.
- Отчёт о допуске полного каталога независимо сверяет два прохода и итоговые количества в перечне до статуса PASS.

## Вне области действия

Генерация Excel-книг, сравнение, запись, проверки Manage, изменение схем/значений и изменение индексов.
