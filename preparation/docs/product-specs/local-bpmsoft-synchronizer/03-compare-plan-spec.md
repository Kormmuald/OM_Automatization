# Дочерняя спецификация 03: строгое сравнение только для чтения и неизменяемый план

Статус: **кандидат; парсер и сравнение не реализованы**.

## Цель

Преобразовать валидную пару Excel-книг и актуальное состояние целевой системы, полученное только для чтения, в одну детерминированную модель изменений, из которой создаются неизменяемый машиночитаемый план и HTML-отчёт.

## Требования


- **CMP-001** Операция сравнения валидирует пару Excel-книг через дочернюю спецификацию 02 и читает целевую систему через дочернюю спецификацию 01; ни одна конечная точка записи недоступна.
- **CMP-002** Канонические правила сравнения определены для каждого разрешённого `Desired*`; неуказанное поле не создаёт операцию.
- **CMP-003** Идентичность существующей сущности — серверные Id/UId + слой пакета; предлагаемая зависимость — имя схемы/столбца только в контексте локального графа черновика; глобальное сопоставление Name/Code запрещено.
- **CMP-004** План исключает удаление, переименование, изменение типа/пакета/использования существующей сущности, операции с индексами и все виды вне списка разрешённых; неподдерживаемое намерение создаёт именованный блокер.
- **CMP-005** Значения справочников различают `Null`, `EmptyString`, `Value`, типизированную каноническую форму и приоритет ссылок.
- **CMP-006** Стабильный ключ операции, граф зависимостей и полный порядок детерминированы. Цикл, повторяющийся производитель или неразрешённая зависимость блокируют выполнение.
- **CMP-007** План и HTML-отчёт строятся из одного канонического представления в памяти и имеют одинаковые наборы операций/количества/блокеры.
- **CMP-008** План содержит версию схемы, ID запуска, время создания, хеши обеих Excel-книг, шаблон/базовое состояние пары, отпечатки целевой системы/затронутого состояния, версию списка разрешённых операций, упорядоченные операции и начальное значение/материал выборки для браузера.
- **CMP-009** План записывается один раз. Apply проверяет точные байты/семантический хеш и не вызывает логику сравнения.
- **CMP-010** Любое изменение связанного входа, устаревшее затронутое состояние, неизвестная версия плана или изменённая операция делает план недействительным до записи.
- **CMP-011** Пустая разница создаёт проверяемый результат без действий, а не пустую сессию Apply.
- **CMP-012** Отчёт о блокерах включает безопасную причину, затронутые стабильные ключи, исходную ячейку/путь и способ устранения без исходных секретов.

## Именованные блокеры

`RENAME_NOT_SUPPORTED`, `TYPE_CHANGE_NOT_SUPPORTED`, `PACKAGE_TRANSFER_NOT_SUPPORTED`, `DELETE_NOT_SUPPORTED`, `INDEX_SYNC_UNRESOLVED`, `INVALID_REFERENCE_ID`, `REFERENCE_TOKEN_UNRESOLVED`, `DERIVED_FIELD_TAMPERED`, `PAIR_MISMATCH`, `STALE_TARGET`, `UNSUPPORTED_SHAPE`, `DEPENDENCY_CYCLE`.

## Приёмка и валидация

- Эталонные фикстуры сравнения: создание/обновление/отсутствие действий, Null/EmptyString, приоритет ссылок, предлагаемая зависимость и каждый блокер.
- Тесты свойств: перестановка строк Excel-книги и перечисление словаря не изменяют семантику плана/хеш/порядок.
- Контрактный тест перехватывает все HTTP-вызовы и доказывает соблюдение списка разрешённых операций только для чтения.
- Изменение одного связанного поля/хеша/отпечатка приводит к ошибке предварительной валидации Apply без записей.
- Независимая сверка доказывает, что операции отчёта в точности равны операциям плана.

## Вне области действия

Частичное одобрение, интерактивное изменение отчёта, автоматическое исправление, Apply, планирование индексов и обратная запись в Excel-книги.
